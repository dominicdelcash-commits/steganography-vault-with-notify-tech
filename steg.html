Security & Dynamic Honeypot Architecture
1. Dynamic First-Wrong Binding: When an intruder enters an incorrect password, that specific string is dynamically locked as the decoy key for the session. The harmless message is revealed, and an immediate privacy-preserving alert is dispatched to your device.
2. Zero Credential Leakage: In compliance with security standards (NIST/OWASP), raw password strings are never transmitted over network telemetry. Only non-sensitive metadata (timestamp, file name, input length) is communicated.
3. Alpha Channel Safety in LSB: Pixel manipulation strictly touches Red, Green, and Blue channels (leaving Alpha at 255). This eliminates color channel premultiplication distortion.
4. Push Alert Integration: Direct alerts dispatched to your private ntfy topic using query parameters to prevent HTTP header encoding errors.
